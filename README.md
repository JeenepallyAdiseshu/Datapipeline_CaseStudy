Hospital Patient Care Analytics

📌 Overview

Hospital Patient Care Analytics is a beginner-friendly Data Engineering case study that processes hospital data collected from different systems.

The hospital has information about:

Patients

Appointments

Laboratory reports

Wearable health data

Doctor consultations

The main purpose of this project is to take raw CSV data, clean and transform it using Python, store the processed data in a SQL database, and then use SQL queries to generate useful hospital analytics.

🎯 Problem Statement

A hospital collects patient-related information from different systems. Since the data is stored separately, it can be difficult to understand the complete patient information and hospital operations.

The hospital needs a simple data engineering solution that can:

Collect data from different sources.

Check the quality of the data.

Clean and transform the data.

Connect related datasets.

Analyze patient and hospital information.

Store the processed data in a database.

Use SQL to generate useful metrics.

This project demonstrates an end-to-end hospital data engineering pipeline. I collected data from multiple CSV files, inspected and cleaned the data using Python and Pandas, performed basic analysis, connected related datasets using patient_id, and created a patient-level summary. After processing the data, I stored it in a SQL database and used SQL queries to calculate useful hospital metrics. This project helped me understand how raw data moves through different stages of a data engineering pipeline and becomes useful information.
